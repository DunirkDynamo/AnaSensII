# AnaSens2

AnaSens2 is an electrochemical analysis pipeline for voltammogram preprocessing, peak extraction, calibration, and visualization.

This repository is being migrated from script-based workflows to an object-oriented package under `src/anasens`.

## Highlights

- Source-layout Python package
- CLI entrypoint: `anasens`
- PySide6 synthwave GUI shell with Pipeline, integrated Plotter-Fitter Curve Builder, and Inverse Estimation tabs
- Sphinx autodoc-ready docs
- CI and docs workflows for GitHub
- Tag-triggered executable build workflow scaffold

See `QUICK_START.md` for installation and command examples.
